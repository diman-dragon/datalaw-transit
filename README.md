# DataLaw Transit 2.0.0

Офлайн-приложение с расписанием общественного транспорта Белграда (Capacitor 8, Android).
Приложение **ничего не скачивает само**: расписание загружается по кнопке в настройках с портала data.gov.rs (открытый GTFS).

## Что в приложении

Четыре вкладки внизу: **Избранное** (слева, открывается первой), **Линии**, **Изменения**, **Настройки** (справа).

- **Избранное.** Карточка линии: номер слева, справа две строки в рамках — обе конечные, между ними стрелки ⇅.
  Под названием каждой конечной — ближайшее отправление от неё («14:25 · через 12 мин», после последнего рейса — «завтра 04:10»).
  Названия всегда в одну строку (без переносов). Нажатие на строку открывает линию в этом направлении.
- **Линии.** Поиск (по номеру и по конечным), фильтр-сетка: Все / Трамваи / Тролл. / Дневные / Ночные / Экспресс / Пригор. / Сербиявоз
  (показываются только категории, которые есть в файле), выровненная сетка номеров. Прокручивается только список.
- **Линия.** Закреплённый блок: номер (и ★) → карточка направления (нажатие меняет направление) → Будни / Суббота / Воскресенье
  (сегодняшний день выбран и помечен) → «Расписание» (мелко — срок действия) и «Остановки» (пока неактивно).
  Ниже прокручивается только расписание «час — минуты»; для сегодняшнего дня оно сразу прокручено к текущему часу, ближайший рейс выделен.
- **Изменения.** Актуальные изменения с https://bgprevoz.rs/linije/aktuelne-izmene (работы, закрытые остановки и т. п.):
  «Действуют сейчас» и «Скоро начнутся», период, тип, затронутые линии (свои избранные выделены рамкой), фильтр «Мои линии».
  Нажатие на запись открывает полный текст. **Скачивается только по Wi-Fi** (мобильный интернет и VPN не подходят; проверка перед каждым запросом),
  автоматически при запуске и при открытии вкладки, если данным больше 6 часов, и кнопкой ⟳. Скачанное хранится на телефоне и доступно без сети;
  записи, снятые с сайта или закончившиеся, пропадают при следующем обновлении. Точка на вкладке — есть новые, которые вы ещё не видели.
- **Настройки.** «Загрузить расписание» (скачивание с data.gov.rs, проверка, подтверждение, уведомления), источники, тема, версия.
- **Системная «назад»**: закрывает окно → на шаг назад → с «Линий»/«Настроек» в «Избранное». В «Избранном» ничего не происходит.
- **Напоминание**: раз в месяц, при первом открытии, окно «Проверьте расписание».

## Загрузка расписания

Настройки → **Загрузить расписание**. Приложение скачивает два GTFS-архива (адреса в `src/feeds.ts`): городской транспорт и пригородные автобусы,
собирает данные, показывает сводку и замечания и только после подтверждения заменяет прежнее расписание. Если любой источник не скачался
или архив повреждён — прежние данные не трогаются, причина показана в уведомлении. Категории: трамваи, троллейбусы, дневные, ночные
(определяются по времени отправлений), пригородные (из пригородного фида), экспресс (`E…`/`A…`), Сербиявоз (`rail`; появится, если в источник добавить его GTFS).

Чтобы добавить источник (например, GTFS Сербиявоза), допишите его в `FEEDS` в `src/feeds.ts`.

Загрузка из JSON-файла (`src/validate.ts`, `tools/collect_gsp.py`) пока отключена в интерфейсе; код проверки оставлен.

## Что убрано относительно 1.x

Сравнение версий, поиск и экран остановок, настройка дат смены, недавние запросы,
остановки в избранном. Данные 1.x не читаются — после обновления нажмите «Загрузить расписание».

## Разработка

```
npm install
npm test          # проверка файла, расписание, поиск, напоминание
npm run typecheck
npm run dev
```

## Сборка APK (GitHub Actions)

Как раньше: приватный репозиторий → Actions → «Android APK». Ключ подписи `keystore/` постоянный, `versionCode` растёт,
APK ставится поверх. Версия берётся из `package.json` (сейчас **2.0.0**).

## Структура

- `src/gtfs/` — разбор GTFS (в Web Worker), `src/importer.ts` — скачивание, `src/feeds.ts` — источники. `src/validate.ts` — проверка JSON (пока не используется). `src/dataset.ts`, `src/db.ts`, `src/store.ts` — набор данных, IndexedDB, память.
- `src/schedule.ts` — тип дня, ближайшее отправление, сортировка. `src/search.ts`, `src/format.ts`, `src/remind.ts`, `src/prefs.ts`.
- `src/changes.ts` (разбор страницы), `src/changes-sync.ts` (скачивание и хранение), `src/net.ts` (проверка Wi-Fi).
- `src/ui/` — экраны (`fav-view`, `lines-view`, `route-view`, `settings-view`), навигация и «назад» (`nav.ts`), уведомления и окна (`overlay.ts`).
